## Les questions posées

1. **Quelles succursales performent** le mieux, et sur quels indicateurs ?
2. **Quels jours, quelles heures** concentrent les ventes ?
3. **Quel effet du mode de paiement** sur le panier ?
4. **Quels écarts de marge** entre les lignes de produits ?

Le détail — lecteur visé, décisions à éclairer, indicateurs retenus — est dans le [cadrage](docs/01-cadrage.md).
